# GUIÓN DE EXPOSICIÓN — TURNIFY SALUD

## 1. PRESENTACIÓN

> BUENAS, SOMOS EL EQUIPO DE TURNIFY SALUD. CREAMOS ESTA PÁGINA PARA QUE LAS PERSONAS PUEDAN ENCONTRAR CENTROS MÉDICOS, CONOCER SUS ESPECIALIDADES Y, COMO OBJETIVO FUTURO, ORGANIZAR SUS TURNOS DESDE UN MISMO LUGAR.

## 2. INICIO Y ACCESOS RÁPIDOS

> EN LA PORTADA PRESENTAMOS LA IDEA PRINCIPAL Y DESTACAMOS LOS ACCESOS MÁS IMPORTANTES. DESDE ESTAS TARJETAS SE PUEDE IR AL DIRECTORIO, A LA SOLICITUD DE TURNO, A LAS ESPECIALIDADES Y A CONTACTO. EN CELULARES, LAS TARJETAS SE PUEDEN RECORRER COMO UN CARRUSEL.

## 3. BÚSQUEDA DE CENTROS

> EL BUSCADOR PERMITE ELEGIR UNA ESPECIALIDAD Y ESCRIBIR UNA LOCALIDAD. JAVASCRIPT COMPARA ESOS DATOS CON LOS CENTROS DISPONIBLES Y OCULTA LAS TARJETAS QUE NO COINCIDEN. EN ESTA VERSIÓN, LOS DATOS SON DE EJEMPLO.

## 4. CENTROS DESTACADOS Y DIRECTORIO

> CADA TARJETA MUESTRA EL NOMBRE DEL CENTRO, SU UBICACIÓN, LAS ESPECIALIDADES Y UN ACCESO PARA CONSULTAR TURNOS. TAMBIÉN SE PUEDE MARCAR UN CENTRO COMO FAVORITO. LOS FAVORITOS SE GUARDAN EN ESTE NAVEGADOR, NO EN UNA CUENTA PERSONAL.

## 5. ESPECIALIDADES

> ESTA SECCIÓN RESUME ALGUNAS ÁREAS MÉDICAS PARA QUE SEA MÁS FÁCIL EXPLORAR LAS OPCIONES. USAMOS UNA CUADRÍCULA QUE SE ACOMODA A DISTINTOS TAMAÑOS DE PANTALLA.

## 6. PRÓXIMAMENTE

> EN ESTA HOJA DE RUTA MOSTRAMOS CÓMO NOS GUSTARÍA HACER CRECER TURNIFY: AGREGAR TURNOS DISPONIBLES EN TIEMPO REAL, CUENTAS PERSONALES, RECORDATORIOS Y HERRAMIENTAS PARA LOS CENTROS. SON OBJETIVOS FUTUROS; LA PÁGINA ACTUAL TODAVÍA NO RESERVA TURNOS REALES.

## 7. CÓMO FUNCIONA Y CONTACTO

> LA PÁGINA “CÓMO FUNCIONA” EXPLICA EL RECORRIDO PARA BUSCAR UN CENTRO Y PREPARAR UNA SOLICITUD. EN CONTACTO HAY UN FORMULARIO DE MUESTRA. AMBOS AYUDAN A MOSTRAR CÓMO SERÍA LA EXPERIENCIA, PERO NO SE ENVÍAN DATOS A UNA CLÍNICA.

## 8. SOLICITUD DE TURNO

> EL FORMULARIO PERMITE COMPLETAR LOS DATOS DE UNA SOLICITUD DE EJEMPLO. JAVASCRIPT PUEDE PRESELECCIONAR EL CENTRO ELEGIDO Y EVITA SELECCIONAR UNA FECHA ANTERIOR A HOY. AL ENVIARLO, MUESTRA UNA CONFIRMACIÓN, PERO NO CREA UNA RESERVA REAL.

## 9. INICIO DE SESIÓN Y REGISTRO

> DISEÑAMOS LAS PANTALLAS DE INGRESO Y REGISTRO PARA MOSTRAR CÓMO PODRÍA SER EL ACCESO DE UNA PERSONA. POR AHORA, LOS FORMULARIOS SOLO VALIDAN LOS CAMPOS Y MUESTRAN UN MENSAJE: NO GUARDAN CONTRASEÑAS NI CREAN CUENTAS.

## 10. CÓMO ESTÁ HECHO

> USAMOS HTML PARA ORGANIZAR EL CONTENIDO, CSS PARA EL DISEÑO Y JAVASCRIPT PARA LAS INTERACCIONES. BOOTSTRAP NOS AYUDA CON LA GRILLA Y LOS COMPONENTES RESPONSIVE. LOS ARCHIVOS ESTÁN SEPARADOS EN PÁGINAS, ESTILOS, JAVASCRIPT E IMÁGENES PARA QUE SEA MÁS FÁCIL ENCONTRAR CADA PARTE.

## 11. GIT Y GITHUB

> USAMOS GIT PARA REGISTRAR LOS CAMBIOS DEL PROYECTO Y GITHUB PARA GUARDAR Y COMPARTIR EL REPOSITORIO. ASÍ PODEMOS VOLVER A VERSIONES ANTERIORES Y TRABAJAR CON UN HISTORIAL.

## 12. CIERRE

> TURNIFY SALUD ES HOY UNA DEMOSTRACIÓN ACADÉMICA. PARA QUE LA PUEDA USAR EL PÚBLICO, EL SIGUIENTE PASO SERÍA CONECTARLA A UN SERVIDOR Y A UNA BASE DE DATOS, ACORDAR LA DISPONIBILIDAD CON LOS CENTROS Y PROTEGER LOS DATOS PERSONALES. MUCHAS GRACIAS.
